# fond-cabin-tool

Compilers · CUDA · Distributed Systems

折腾中的小玩具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/fond-cabin-tool.git
cd fond-cabin-tool
chmod +x run.sh
```
